# Justice Dance

A small, expressive landing page for Justice Dance. The project is intentionally dependency-free so it can be opened locally or hosted directly from GitHub Pages.

## Run locally

Open `index.html` in a browser.

## Project files

- `index.html` — page structure and accessible content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and current-year footer
- `.gitignore` — common local files excluded from Git
